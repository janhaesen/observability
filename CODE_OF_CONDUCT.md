# Code of Conduct

This project aims to be a respectful, constructive place to collaborate.

## Expected behavior

- Be respectful in technical disagreement.
- Assume good intent and give actionable feedback.
- Keep discussions focused on the code, design, and user impact.
- Welcome contributors with different experience levels.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks
- Trolling, intimidation, or repeated bad-faith argument
- Publishing private information without permission
- Conduct that makes collaboration hostile or unsafe

## Scope

This code of conduct applies to project discussions, issues, pull requests, reviews, and other repository interactions.

## Reporting

If you experience or witness unacceptable behavior, contact the repository owner through a private GitHub channel rather than escalating publicly in the thread.

The maintainers may remove, edit, or reject comments and contributions that violate this code of conduct.
